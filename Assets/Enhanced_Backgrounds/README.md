# Enhanced Backgrounds — Just Aliens

These are ten separately generated, cinematic background designs. Each PNG is 1254 × 1254, square, intended as a new alternative background set alongside `Assets/Background/`. These files are not automatic replacements and are not wired into the collection generator yet.

The originals under `Assets/Background/` remain unchanged.
